# Code of Conduct

Retort adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every space of the project: issues, pull
requests, discussions and any other channel.

In short: be welcoming and kind, assume good intent, critique ideas rather
than people, and accept that maintainers will remove behaviour that makes
others feel unwelcome — harassment, personal attacks, sexualised language or
imagery, publishing others' private information, and similar conduct.

To report a problem, contact the maintainers privately through GitHub (use
*Report content* on the comment or issue, or a private message to a
maintainer). Reports are handled confidentially, following the Covenant's
enforcement guidelines.

Retort — portable build
=======================

Requirements (from your distribution): GTK 4.14 or newer, libadwaita 1.5 or
newer, and FFmpeg. Ubuntu 24.04+, Debian 13+, Fedora 41+, openSUSE
Tumbleweed / Leap 16, Arch and RHEL/AlmaLinux 10 qualify.

Install for your user:            ./install.sh
Install for everyone:             sudo ./install.sh --system
Run without installing:           ./bin/retort   (settings need an install)
Uninstall:                        ~/.local/share/retort/uninstall.sh
                                  (or /usr/local/share/retort/uninstall.sh)

This build can check for updates once a day if you turn it on in
Preferences. Nothing else ever goes over the network.

Source, issues and other packages: https://github.com/oreo1298/FreeMediaConverter
